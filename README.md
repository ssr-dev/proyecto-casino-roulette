## 🎯 Descripción del Proyecto

Sistema de ruleta de casino europea desarrollado como proyecto final para la materia de Programación 3. La aplicación incluye:

- **Backend robusto** con Spring Boot y API REST
- **Frontend moderno** con React y Vite
- **Animaciones realistas** de la ruleta
- **Sistema completo** de apuestas y gestión de saldo
- **Interfaz intuitiva** y responsive
